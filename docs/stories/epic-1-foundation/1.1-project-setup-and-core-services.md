## Class/Interface Definitions

```csharp
// IService - Base interface for all services
public interface IService
{
    void Initialize();
    void Shutdown();
    bool IsInitialized { get; }
}

// ServiceLocator - Central service registry
public class ServiceLocator : MonoBehaviour
{
    private static ServiceLocator _instance;
    private Dictionary<Type, IService> _services;
    
    public static T GetService<T>() where T : class, IService;
    public static void RegisterService<T>(T service) where T : class, IService;
    public static void UnregisterService<T>() where T : class, IService;
}

// IGameManager - Game state management interface
public interface IGameManager : IService
{
    GameState CurrentState { get; }
    void ChangeState<T>() where T : GameState;
    event System.Action<GameState, GameState> OnStateChanged;
}

// GameManager - Main game state controller
public class GameManager : MonoBehaviour, IGameManager
{
    private GameState _currentState;
    private Dictionary<Type, GameState> _states;
    
    public void Initialize();
    public void ChangeState<T>() where T : GameState;
    private void Update();
}

// GameState - Base state class
public abstract class GameState
{
    protected IGameManager gameManager;
    
    public virtual void Enter() { }
    public virtual void Update() { }
    public virtual void Exit() { }
}
```

# Notes

**Implementation Notes:**

- ServiceLocator should be implemented as a singleton with thread-safe access
- GameManager should persist across scene loads using DontDestroyOnLoad
- All services should implement proper cleanup in Shutdown method

**Design Decisions:**

- ServiceLocator pattern chosen over dependency injection container for simplicity
- State machine pattern for GameManager enables clear separation of game phases
- Bootstrap scene ensures consistent initialization order

**Future Considerations:**

- ServiceLocator can be extended with service priorities and dependencies
- GameManager can support nested states for complex game phases
- Additional core services (Audio, Input, Save) will integrate with this foundation
